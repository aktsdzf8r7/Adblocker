Schild Adblocker

Einstellungen

Zugriff auf Webseiten erlauben

Damit Schild Werbung auf allen Webseiten ausblenden kann, braucht es Zugriff auf die Seiten. Schild liest dabei keine Daten aus und sendet nichts ins Internet.

Hinweis

Schutz

Filterlisten

Die Listen sind in die Erweiterung eingebaut und werden mit jedem Update der Erweiterung aktualisiert.

Ausnahmen (Seiten ohne Blocker)

Eine Domain pro Zeile, z. B. example.com. Gilt auch für Subdomains.

Gespeichert ✓

Eigene Filter

Adblock-Plus-Syntax, ein Filter pro Zeile. Beispiele:
||werbung.example.com^ – Domain blockieren
example.com##.werbebanner – Element auf einer Seite ausblenden
##.sponsored-box – Element überall ausblenden
@@||example.com/ad.js – Ausnahme
